# Vehicle Fuel Efficiency Analysis

## Overview
This project analyzes the Auto MPG dataset to understand which factors 
affect vehicle fuel efficiency (mileage) using Python.

## Tools Used
- Python
- Pandas (data cleaning & analysis)
- NumPy
- Matplotlib (data visualization)

## Dataset
Auto MPG dataset containing details of 398 vehicles including weight, 
horsepower, cylinders, model year, and mileage (MPG).

## Key Insights
- Vehicle weight and MPG show a strong negative correlation — 
  heavier vehicles have lower fuel efficiency
- Vehicles with 8 cylinders have significantly lower average MPG 
  compared to 4-cylinder vehicles
- Fuel efficiency improved gradually from 1970 to 1982 due to 
  advancements in engine technology
- Horsepower also shows a negative correlation with MPG

## How to Run
Open the notebook in Google Colab and run all cells sequentially.
